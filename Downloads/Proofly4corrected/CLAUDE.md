# PROOFLY — CORE ARCHITECTURAL PRINCIPLES

- **Evidence-First**: Proofly shifts student readiness evaluation from keyword claims to verifiable evidence (Projects, Certificates, GitHub Repos, Coursework).
- **Professional Polish Theme**: Purple + Light UI (`bg-slate-50`, `bg-white`, `border-slate-200`, `text-purple-700`, `text-slate-900`).
- **Readability is Critical**: Large clear typography, comfortable line-heights, no unreadable 10px fonts, WCAG AA contrast.
- **The Core Loop**: `Opportunity` → `Requirements` → `Evidence` → `Readiness` → `Skill Gap` → `Career Trial` → `New Evidence` → `Updated Readiness` → `Progress`.
- **Explainability**: Every match follows `Requirement → Evidence → Explanation → Action`.
- **Non-Judgmental Voice**: Honest, actionable, encouraging. Never shame missing skills; provide bridge trials.
- **Career Trial**: Realistic workplace micro-simulations evaluated with rubrics, automatically converting into verified evidence.
- **SkillSwap**: Peer matching on complementary skills (`User A Gap ∩ User B Strength`).
- **Data Security**: Secure client/server separation with Row Level Security principles.
